# Codex3N 1.7.6-3n.1

同步 CodexPlusPlus 最新主分支提交 `e53549ca`，包含官方 1.7.2–1.7.6 更新及后续提交。

- Codex++ 界面与后台服务合为同一应用，新增实时服务健康状态；关闭窗口收起到托盘，退出时清理自有服务。
- 新增 Codex 隔离多开，分别保存供应商配置、会话和用户数据；支持单一 Responses、Chat Completions 供应商及智谱。
- 新增 Claude Code 动态汉化管理，支持 Windows 普通安装和 MSIX 的受管副本，以及 macOS 副本；保留官方应用和 `app.asar`。
- 语音输入支持本地 SenseVoiceSmall INT8，手动下载并校验模型后在本机转写。
- 同步纯 API 显式鉴权、逐模型 Fast 配置、搜索历史压缩兼容、原生压缩与 Gemini 搜索转换修复。
- 更新供应商、MCP、Skills 与会话管理页面；保留个人版命名 Key、模型排序和手工窗口、会话分页与安全清理。
- 同步 macOS 单应用迁移、更新 helper 签名和隐藏兼容壳修复；个人更新源、校验和与版本门禁继续生效。

上游已撤下 Codex++ 会话分享和文件导入入口。升级后请完整退出并重开 Codex++ 与 Codex。

Windows 自动回归已通过，CI 覆盖跨平台测试与产包。各平台安装、升级与真实宿主界面仍需实际使用验证。
