## 维护约定

- 按业务领域归类，不按每个按钮、功能或代码模块单独建文档；相关功能写在现有文档的小节内，只有现有分类容纳不了的独立业务才新增文件。
- README 只做导航，AGENTS.md 只放协作约定；代码核心拆分后的职责和唯一入口记录在对应业务文档，避免同步上游时恢复重复实现。
- 修改、重命名或删除功能时，同一提交更新对应文档，移除失效入口；只记录当前仍存在的行为。
- 记录通用规则与数据来源，不把某一供应商的当前模型名单或某次发布版本当作永久约定。示例只是示例，不能成为实现中的白名单。
- 配置键、接口字段和代码路径属于实际契约，应明确写出并随代码同步维护。
- 文档中的代码路径相对于仓库根目录；历史记录只解释缘由，当前代码和测试才是事实依据。
