## Codex3N 1.4.0-3n.2

本版为个人功能修复与开销优化，不含上游同步。

### 快速切换 Key

- 换 Key 不再要求先打开「启用供应商配置切换」。总开关关闭时只更新 Key 的落点：`auth.json` 的 `OPENAI_API_KEY`，或 config.toml 里 Codex++ 写入的 `experimental_bearer_token`；模型、上下文、MCP 等其它配置一个字节都不动，写前同样备份到 `~/.codex/backups/codex-plus-live-*`。
- 总开关打开时仍按原来的整份供应商配置应用，行为不变。
- 落点不唯一（两处都有 Key）、Key 写在 `api_key` / `bearer_token` 等非标准字段、供应商用 `env_key` 声明 Key 来自环境变量，或通用环境变量（`OPENAI_API_KEY` 等，优先级高于 `auth.json`）已设置时，直接报错说明原因，不做"写了但 Codex 没读"的假成功。

### Codex++ 密钥页

- 下拉框不再因总开关关闭而禁用，只有切换请求进行中才禁用。
- 「当前 Key」按 Codex 实际在用的 Key 显示：读 live 配置里的 Key 再匹配命名 Key。总开关关闭时存档的 `activeApiKeyId` 可能停在最后添加的那个 Key，不再据此显示；匹配不上时明确提示"实际在用的 Key 不在这个列表里"。
- 重新打开面板会重画已读取的 Key 列表，不再一直停在"正在读取当前供应商…"。
- 下拉列表配色跟随面板深浅色，不再白底配近白色文字。
- 提示时长改为按内容给：短提示 3 秒、长报错 6 秒、带"撤销"的仍 10 秒。
- 供应商总开关说明改为"开启后可整份切换供应商配置；关闭时只在 Codex++ 面板里更换当前 Key，模型与上下文等其它配置不动。"

### 开销

- 注入页的设置对象改为按 `localStorage` 原文、后端设置对象、皮肤主题三者缓存，滚动监听和逐帧对齐路径不再重复 `JSON.parse`。
- 语音按钮兜底扫描（原来每 1.5 秒一次全文档查询）和外观主题的定时全量检查（每 4 秒）在页面不可见时跳过；DOM 变化触发的路径保留。
