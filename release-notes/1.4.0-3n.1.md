## Codex3N 1.4.0-3n.1

本版同步上游 Codex++ 1.4.0（`070be57`）。

### 上游 1.4.0

- 重启后若原生浏览器文件没能恢复，不再中断启动：Codex 照常拉起，管理工具改为提示“原生浏览器文件恢复失败，仍会继续启动”。
- 协议代理固定端口在重启瞬间会等前任交还监听，不再一次失败就整个启动中止；Windows 上旧套接字短暂占用的 10013 也在这段窗口内重试，只有窗口耗尽仍失败才提示端口被系统保留。
- 启动器改为只跟随本次启动的 Codex 进程，机器上其它 Codex 进程不会让它一直占着原生浏览器监控（macOS 按调试端口精确匹配）。
- 恢复 Windows 应用包 AUMID 的真实 manifest 读取，修复“该进程没有程序包标识符”。
- 选择 Chat Completions 时 OpenAI 会话自动回到 Custom；Responses API 下“纯标准协议”开关置灰，仅 Chat Completions 可用。
- 供应商编辑器动作按钮对齐；macOS 打包在卷卸不掉时先释放 hold 住镜像的后台进程再重试。

### 本版个人改动

- 自动检查失效会话改为只查询已隐藏的会话 ID，不再每次遍历全部会话记录与恢复备份，重新启动后不会立刻抢占资源。
- 复核周期由 1 分钟放宽到 5 分钟，且页面隐藏时不触发；手动“检查并隐藏失效会话”和管理器删除预览仍是全量扫描。
- 空闲心跳不再重复写诊断日志：`/backend/status` 与 `/diagnostics/log` 成功时不再记录路由与回执，失败照旧记录，业务诊断事件不受影响。
